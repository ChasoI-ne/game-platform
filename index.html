    ちゃそい

    プログラミング、ゲーム制作、AI活用、音楽。興味のあることを、実際に動く形にするまで作るのが好きです。

    興味・趣味

    • 音楽・吹奏楽 — 音楽を聴くこと、吹奏楽、音楽制作・編曲
    • 音楽ゲーム — 『太鼓の達人』など。高難易度譜面やリズムの分析
    • ゲーム・配信文化 — VTuberや配信の視聴、Minecraft
    • 3D・デザイン — アイソメトリック表現、ゲームUI、世界観づくり

    技術・スキル

    主にWeb技術を使って、ブラウザ上で動くアプリやゲームを企画・制作しています。

    • HTML / CSS / JavaScript / TypeScript
    • Web Audio API
    • Three.js
    • IndexedDB、JSON、Base64 などのデータ処理
    • Blender と MCP を組み合わせた3D制作

    制作してきたもの

    • PSS Studio — 音楽ゲームの譜面エディタ
    • Astra OS — ブラウザ上で動く仮想OS
    • KTKエディタ — カトカトーン形式の音楽シーケンサー
    • INDIEPORT — ゲーム投稿サイト
    • NO MAN'S LAND — 制作中のゲーム企画

    AIとの開発

    • OpenCode — コーディングエージェントとして調査・実装・評価を体系化
    • Claude / ChatGPT — 実装、企画整理、仕様書、設計レビュー
    • Notion — プロジェクト情報や知識のナレッジベース

    大切にしていること

    • 機能だけでなく、使える・面白い・UIが整っている完成度
    • 根本原因を調査して直す
    • 動作や画面表示まで実際に確認してから検証済みとする
    • READMEや仕様書で、目的と品質基準を明確にする

    これからの関心

    • AIエージェント中心の開発ワークフロー
    • Blender や MCP を組み合わせた3Dゲーム制作
    • ブラウザ技術による完成度の高いゲーム・アプリ
    • 音楽ゲーム・音楽制作のツールと作品づくり
